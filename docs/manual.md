## 1. はじめに

**LaiPDF** は Laiweb 契約者向けに提供される、Windows 用のローカル型 PDF 編集アプリケーションです。中小企業の日常業務でよくある PDF 作業（押印・テキスト追加・結合・分割・OCR 等）を、3 クリックで完了できることを目指して開発しました。

### 特徴

- **完全ローカル動作**: PDF はネット送信されず、お客様の PC 内で完結
- **日常業務向け**: 印鑑・署名・テキスト追加など中小企業のユースに最適化
- **重ね方式編集**: 元 PDF を直接書き換えず、注釈レイヤーとして上書き
- **OCR 機能**: スキャン PDF からも日本語テキストを抽出可能

### LaiPDF でできないこと

- 元 PDF 内のテキストを直接編集（Adobe Acrobat Pro のレベル）
- → 代替として「白塗り編集」機能で擬似的な書き換えが可能

## 3. インストール手順

### ステップ 1: インストーラーを実行

配布された `LaiPDF-1.0.3-setup.exe` をダブルクリックします。

### ステップ 2: SmartScreen 警告への対処

「**Windows によって PC が保護されました**」と青い画面が表示されます。

1. 画面内の「**詳細情報**」をクリック
2. 下に表示される「**実行**」をクリック

これは LaiPDF が「電子署名なし」で配布されているためです。Laiweb 契約者向けの社内ツールとして安全に動作します。

### ステップ 3: インストール先選択

デフォルトのまま「**次へ**」で問題ありません。

### ステップ 4: 完了

デスクトップに **L'aide ロゴのショートカット**が作成されます。

## 6. 基本操作

### PDF を開く

3 通りあります：
- **ホーム画面に PDF をドラッグ&ドロップ**
- **「ファイルを選択」ボタン**から選ぶ
- 「画像 (JPG/PNG) から PDF 作成」ボタンで新規 PDF を作成

### ページめくり

- ツールバーの「← 前 / 次 →」ボタン
- 左のサムネをクリック
- キーボードの矢印キー（PDF にフォーカス時）

### ズーム

- ツールバーの「− / ＋」ボタン
- 50% 〜 300% の範囲

### 保存

- ヘッダー右の「**💾 保存**」ボタン（または **Ctrl+S**）
- 名前を付けて保存ダイアログ → 任意の場所に保存

### 閉じる

- ヘッダー右の **✕** ボタン
- 未保存の変更があれば確認ダイアログ表示

## 7. 注釈・編集機能

LaiPDF の編集はすべて「**注釈レイヤー方式**」です。元 PDF を直接変更せず、上から重ねた注釈は配置後に**自由に移動・サイズ変更・削除**が可能。保存時に PDF に焼き込まれます。

### 7.1 テキスト追加

1. 左サイドバー「**テキスト追加**」をクリック
2. PDF 上の任意の位置をクリック
3. ダイアログでテキスト入力 + フォントサイズ + 色を選択（Ctrl+Enter で確定）
4. 配置されたテキストは**ドラッグで移動可能**、× で削除

**日本語対応**: 初回のみ NotoSansCJKjp フォント（16MB）を自動ダウンロード。

### 7.2 印鑑登録 + 押印

#### 印鑑画像の登録

1. ヘッダー右の **⚙ 設定** から印鑑管理を開く（または左サイドバー「印鑑・押印」）
2. 「**＋ 画像を追加**」ボタン → PNG / JPG を選択
3. 推奨: 透過 PNG、256×256px

#### 押印

1. 印鑑管理画面で「**使う**」ボタンクリック
2. PDF 上の任意の位置をクリック → 印鑑が配置される
3. ドラッグで移動、右下の青ハンドルで等比リサイズ

### 7.3 手書き署名

1. 左サイドバー「**手書き署名**」
2. キャンバスにマウスで署名を書く
3. 「この署名を使う」→ PDF 上をクリックで配置（印鑑と同じ操作感）

### 7.4 図形・矢印・マーカー

1. 左サイドバー「**図形・矢印**」→ 形を選択
   - ⬜ 矩形
   - ⭕ 円
   - ➡ 矢印
   - 🖍 マーカー（黄色ハイライト）
2. PDF 上を**ドラッグして範囲指定**
3. 上部のサブツールバーで**色・線幅**を変更可能

### 7.5 白塗り編集（擬似的な文字修正）

元 PDF の文字を直接変更することはできませんが、白塗りで隠して上から書き直せます。

1. 左サイドバー「**白塗り編集**」
2. PDF 上をドラッグで範囲指定 → 白い矩形配置
3. 次に「**テキスト追加**」で上から新しい文字を入力

例：「2025/12/31」→ 数字部分を白塗り → 「2026/01/15」と書き直す

### 7.6 スナップショット

PDF の一部を範囲選択 → 画像として保存・コピー。

1. 左サイドバー「**スナップショット**」
2. PDF 上をドラッグで範囲指定
3. 自動で：
   - クリップボードにコピー（メール / Word / Excel に Ctrl+V で貼れる）
   - PNG ファイルとして保存ダイアログ表示

### 7.7 Undo（元に戻す）

- ヘッダー左の **↶** ボタン
- または **Ctrl+Z**
- 最大 10 操作前まで戻せる

## 8. ページ操作

左のサムネ一覧で操作します。

### 並び替え

- サムネを**ドラッグして別の位置にドロップ**
- ドロップ先がオレンジ枠で強調

### 削除・回転

サムネを**右クリック** → コンテキストメニュー：
- ↻ 右に 90° 回転
- ↺ 左に 90° 回転
- ⟲ 180° 回転
- 🗑 このページを削除

## 9. PDF 変換・整理

### 9.1 PDF 結合

複数の PDF を 1 つにまとめる。

1. PDF を開いた状態で左サイドバー「**PDF を結合**」
2. ファイル選択ダイアログで複数 PDF を選択（Ctrl + クリック）
3. 選択順で末尾に追加される

### 9.2 PDF 分割

1 つの PDF を複数に分ける。

1. 左サイドバー「**PDF を分割**」
2. 方法を選ぶ：
   - **範囲指定**: `1-3, 5, 7-10` 形式（3 つの PDF に分割）
   - **全ページを 1 ファイルずつ**: ページ数分のファイル
3. 各分割ファイルの保存先を順次選択

### 9.3 PDF 圧縮

スキャン PDF などサイズの大きい PDF を縮小。

1. 左サイドバー「**PDF を圧縮**」
2. 品質を選択：
   - 🚀 最小（72dpi / JPEG 50%）— メール添付用
   - ⚖ 標準（96dpi / JPEG 70%）— 推奨
   - ✨ 高画質（150dpi / JPEG 85%）— 印刷用
3. 「圧縮実行」→ 削減率表示 → 「この圧縮版を採用」

**注意**: 圧縮後はテキスト検索・コピーができなくなります（画像化されるため）。

### 9.4 画像から PDF 作成

JPG / PNG 画像を PDF にまとめる。

1. ホーム画面の「**📷 画像から PDF 作成**」ボタン
2. 複数画像を選択（Ctrl + クリック）
3. 選択順で 1 ページずつ PDF 化（A4 縦、中央配置）

## 10. 検索・読取（OCR）

### 10.1 PDF 内検索

通常の PDF（テキストが入っているもの）から検索。

1. ヘッダー右の検索アイコン、または **Ctrl+F**
2. 右上にパネル表示 → キーワード入力
3. 検索結果がリスト表示、クリックで該当ページにジャンプ
4. ヒット箇所は黄色でハイライト

### 10.2 OCR 文字読取

スキャン PDF や画像 PDF からテキスト抽出。

1. 左サイドバー「**OCR 文字読取**」
2. 範囲を選択：
   - 現在ページのみ
   - 全ページ
3. 「**▶ OCR 実行**」
4. **初回のみ**: jpn+eng の言語データを自動ダウンロード（1〜2 分）
5. 認識結果がテキストエリアに表示（編集可能）
6. 「📋 コピー」または「💾 txt として保存」

## 11. 印刷

ヘッダー右の **🖨 印刷アイコン**、または **Ctrl+P**。

### 印刷ダイアログの項目

| 項目 | 説明 |
|---|---|
| プリンター | 接続中のプリンタから選択 |
| 部数 | 1〜999 |
| 印刷するページ | すべて / 現在のページ / ページ指定 |
| カラー / グレースケール | - |
| 向き | 自動 / 縦 / 横 |
| ページサイズ処理 | 合わせる / 実際のサイズ / 特大ページを縮小 / カスタム倍率 |
| 1 枚に複数ページ印刷 (N-up) | 1 / 2 / 4 / 6 / 9 / 16 ページ |
| 両面印刷 | 片面 / 両面（長辺/短辺）|

### プレビュー

右側パネルにプレビュー表示。設定変更（向き・カラー・倍率）は**リアルタイムで反映**されます。スライダー・←/→ ボタンでページ移動可能。

### 印刷ボタン

- 「**🖨 印刷**」: 設定通りに直接プリンタへ送信
- 「**詳細設定…**」: OS のプリンタ標準ダイアログも表示

## 13. トラブルシューティング

### Q. 「Windows によって PC が保護されました」と出る

A. 「**詳細情報**」→「**実行**」をクリックしてください。LaiPDF が電子署名なしのため出る警告で、Laiweb 契約者向けの安全なアプリです。

### Q. 日本語テキスト追加が「失敗しました」と出る

A. 初回はネット接続が必要です（NotoSansCJKjp フォント 16MB を取得）。インターネットに接続してから再試行してください。2 回目以降はキャッシュから読み込みます。

### Q. OCR で「言語データのダウンロードに失敗」

A. 同じくインターネット接続を確認してください。初回のみ jpn+eng データ（合計 ~25MB）を取得します。

### Q. 印刷が真っ黒に出る

A. 内部処理を画像経由に変更済みです。それでも出る場合は「詳細設定…」を試して OS のダイアログ経由で印刷してください。

### Q. PDF が表示されない / アプリが起動しない

A. アプリを完全に終了 → タスクマネージャーで `LaiPDF.exe` が残っていれば終了 → 再起動。それでもダメな場合は再インストールを試してください。

### Q. アンインストール方法

A. **設定 → アプリ → インストールされているアプリ → LaiPDF → アンインストール**。
ライセンス情報・印鑑画像・OCR キャッシュは `%APPDATA%\LaiPDF\` に残るため、完全削除したい場合は手動で削除してください。
