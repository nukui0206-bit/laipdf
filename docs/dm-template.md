## lai-hub BulkEmail で送る前の確認事項

1. ☐ 送信元アドレス = `info@laide.co.jp` (デフォルト mailer)
2. ☐ 宛先 = active 契約者全員（`customers.status = active` フィルタ）
3. ☐ 差し込み変数 `{{customer_name}}` が `customers.name` で置換されること確認
4. ☐ 件名にスパム判定ワード（「無料」「限定」連打など）が入りすぎていないか
5. ☐ テスト送信を 1 件だけ自分宛に流して表示確認

## ライセンス発行フロー（DM 受信者から返信が来たら）

1. `/admin/licenses` → 「新規ライセンス発行」
2. メアド入力（顧客の返信メアド）
3. 顧客プルダウンで該当顧客を選択
4. 「メール送信オン」にチェック → 発行
5. 自動で `info@laide.co.jp` から発行通知メールが送信される
6. 翌月以降の請求は `/admin/customers/{id}` で `monthly_amount += 1500` を手動加算
