# LaiPDF 法務文書

LaiPDF の販売・運用に必要な法務文書一式。

## ファイル一覧

| ファイル | 用途 | 適用先 |
|---|---|---|
| [`commerce-law.md`](./commerce-law.md) | 特定商取引法に基づく表示 | LP / 購入ページの法律必須表示 |
| [`privacy.md`](./privacy.md) | プライバシーポリシー | 全販売チャネル共通 |
| [`laipdf-terms-standalone.md`](./laipdf-terms-standalone.md) | LaiPDF 単独 利用規約 | 新規購入者向け（laipdf.jp 等） |
| [`laipdf-supplementary.md`](./laipdf-supplementary.md) | Laiweb 利用規約への追加 個別規定 | 既存 Laiweb 契約者向け |

## 公開方法

### 一般販売（新規購入者）
- 利用規約 → `laipdf-terms-standalone.md`
- プライバシー → `privacy.md`
- 特商法 → `commerce-law.md`
- 購入時に「利用規約・プライバシーポリシーに同意します」チェックボックスで同意取得

### Laiweb 既存契約者
- 主規約 → 既存の Laiweb 利用規約（laide.co.jp/terms 等）
- 追加 → `laipdf-supplementary.md`
- プライバシー → `privacy.md`
- 特商法 → `commerce-law.md`
- LaiPDF 申込時に「個別規定に同意します」チェックボックスで同意取得

## 公開チェックリスト

公開前に以下を確認:

- [ ] 会社名、所在地、代表者氏名 が最新か
- [ ] 価格が最新か（プラン変更時は要更新）
- [ ] 動作環境が現バージョンと一致するか
- [ ] サーバー URL が正しいか
- [ ] 法務的なチェック（弁護士レビュー推奨、特に第 11 条「免責事項」周辺）

## 法的に重要な注意

本文書は一般的な雛形を基に作成しています。**実際に公開・販売する前に、弁護士による法務チェックを受けることを強く推奨します**。特に以下の点:

- 第 11 条（免責事項）の損害賠償上限額
- 第 8 条 / 個別第 7 条（解約）の通知期間
- 返金ポリシーが消費者契約法・特商法に整合しているか
- B2B / B2C で異なる取り扱いが必要な場合の調整
